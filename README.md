# محلل المسار الحركي — دفع الثقل (Streamlit)

## التشغيل محلياً
```
pip install -r requirements.txt
streamlit run app.py
```

## النشر على Streamlit Cloud
1. ارفعي كل الملفات (app.py, biomech.py, video_pipeline.py, storage.py, requirements.txt, packages.txt) إلى مستودع GitHub.
2. من share.streamlit.io اختاري المستودع والملف الرئيسي `app.py`.
3. ملف `packages.txt` ضروري (مكتبات النظام لـ OpenCV).
4. بيانات اللاعبات تُحفظ في `data/db.json` وقد تُمسح عند إعادة تشغيل الخادم؛ استخدمي زر «نسخة احتياطية» في الشريط الجانبي بانتظام.

## خطوات الاستخدام
1. «اللاعبات»: أدخلي القياسات الجسمية.
2. «تحليل رمية»: اختاري اللاعبة والأسلوب (انزلاقي/دوراني) ويد الرمي، وارفعي فيديو الكاميرا الجانبية و/أو الأمامية.
3. في الكاميرا الجانبية: انقري على مركز الثقل في أول إطار، ثم نقطتي معايرة بمسافة معروفة (قطر دائرة الرمي 2.135 م).
4. اضغطي «بدء التحليل»، ثم تحقّقي من إطارات المراحل (خصوصاً لحظة الإطلاق) وعدّليها بالشرائح.
5. احفظي المحاولة؛ أفضل محاولة تصبح نموذج اللاعبة وتُقارن بها بقية المحاولات.

## شروط التصوير
- الكاميرا على حامل ثابت، عمودية على مستوى الحركة (الجانبية) وعلى ارتفاع الورك تقريباً.
- 60 إطار/ث فأكثر، إضاءة جيدة، الجسم كاملاً داخل الكادر، لباس يُظهر المفاصل.
- ضعي علامة بمسافة معروفة (أو استخدمي دائرة الرمي) في مستوى الحركة.

## حدود علمية
- كاميرا واحدة = زوايا ثنائية الأبعاد؛ تحقّقي من النتائج مقابل Kinovea على عينة قبل اعتمادها في الرسالة.
- سرعة وزاوية الإطلاق تقديرية وتعتمد على تتبع الثقل بعد خروجه (تتحسن بزيادة معدل الإطارات).
- النطاقات المرجعية الافتراضية مبدئية؛ بدّليها بقيم مصادر رسالتك من صفحة «المراجع».
